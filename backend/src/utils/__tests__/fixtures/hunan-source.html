1. 项目概述

1.1. 项目背景

三维数据是公司的重要战略数据资源，但目前存在缺少对三维数据的维护和更新，导致大量三维数据资源丢失、重复录入或成为过期无效数据；已有的三维数据缺乏资源共享；三维模型数据不满足易用性需求等问题，影响三维数据的共享和应用，未能充分发挥三维数据的应用价值。

为提高数据融合贯通效率，助力基层减负，国网设备部会同国网基建部在 2021年开展了输变电工程数字化移交试点工作。实现了基建全过程数据资料的“一键式 ”移交。同时国网湖南省电力公司按照“ 中台+应用 ”建设模式，基于“ 中台+微服务 ”的 IT 架构，开展电网设备三维数据中心建设，新增三维数据管理、三维数据规模共享及纵向同步。统一新建工程三维数据建模与移交标准，目标是“一站式 ”入库。实现三维数据共享应用。变电站和输电线路三维成果共享（运检、基建、调度之间共享），总部和省公司纵向数据贯通（总部与省公司之间共享）。基于电网设备三维数据中心，完成为各部门各专业应用系统提供统一的三维数据共享服务。

1.2. 项目建设需求

1.2.1. 三维数据管理功能需求

基于数据中台完成三维数据管理相关功能开发，功能包括：三维数据质量检查、三维数据上传、三维数据存储和三维数据发布。

1.2.1.1. 三维数据规模功能需求

基于数据中台完成数据规模相关功能开发，功能包括：数据统计、过滤查询、数据规模二维 GIS 分布可视化和任务中心。

1.2.1.2. 三维数据资源管理功能需求

基于数据中台完成数据资源管理相关功能开发，包括元数据管理、数据查询统计、数据操作日志管理、数据更新提醒。

1.2.1.3. 数字化设计成果移交功能需求

根据《国网设备部、基建部关于开展输变电工程数字化移交试点建设工作的通知》，以输变电工程数字化移交基本内容（主要包括结构化数据、输变电工程数据、影像数据、地形数据、图纸数据）为基础，开展数字化移交试点建设，实现基建过程数据资料的“一键式 ”移交。

依据《国网湖南省电力有限公司输变电工程数字化移交工作方案（试行）》中的相关要求，基于运检管控平台按微服务架构开发三维数据中心，纳入业务中台管理，支撑三维模型和数据的集中管理、深化应用和共享服务。

1.2.1.4. 架空输电线路参数化三维模型构建管理需求

基于数据中台，通过使用架空输电线路自动参数化建模模型库和建模工具，实现通用模型高度复用，避免重复建设，降低建模成本；快速高效地创建架空输电线路三维模型，有效提高架空输电线路三维建模效率。

1.2.1.5. 三维数据共享服务需求

实现纵向同步功能，主要内容包括：在运设备三维模型纵向同步服务；数字化设计成果数据纵向同步服务；激光点云数据纵向同步服务；

实现对外服务接口功能，数字化设计成果格式转换功能, 三维数据轻量化处理功能。

1.2.1.6. 三维数据可视化服务需求

实现变电站（换流站）全站场景动态可视，支持变电站/换流站内设备台账信息展示、三维漫游。

实现输电线路三维可视化场景，具备全网线路可视化展示及地图缩放、浏览、查询等功能，可选择不同图层组合展示。

实现变电设备安全距离分析，输电三维校验与分析：包括导线间距离校验、导线对地距离校验、导线对地物距离校验、输电导线弧垂分析。

1.3. 技术描述

1.3.1. 技术选型原则

系统设计遵循公司中台架构和微服务技术进行设计，分为前台、中台和后台三层。前台包括微应用或系统，通过服务调用方式，复用中台的数据服务、业务服务和技术中台服务，或者个性微服务，聚焦用户需求，快速搭建业务应用；中台包括数据中台，为前台提供共性的数据中台服务；后台包括云平台及基础设施，为前台、中台提供标准技术支撑体系与统一的计算存储资源。

电网设备三维数据中心逻辑架构图如下：

__IMG_2__

（1） 基础设施层

基础设施层包括系统运行所需的硬件、软件、网络、操作系统软件等，是系统正常运行和使用的保障，遵守资源利旧原则和可扩展性原则，支持后续方便数据中心迁移上云。

（2） 数据管理层

数据管理层构建电网三维权威数据库，支持四川数据资源统一集中管理和统一共享应用服务。

（3） 数据服务层

数据服务层是所有应用服务的基础。在系统各功能模块的基础上，抽取类似功能构建通用应用服务，既包括数据资源管理服务、三维场景应用服务、三维

GIS 基础服务等公共数据服务，为避免功能重复开发，可将其抽取出来作为通用组件和功能服务供其他应用模块调用，达到业务变更时组件修改即可满足全部系统修改的要求。

（4） 应用层

应用层集中、直观地体现平台的数据中心各项应用服务，面向管控系统、自然灾害监测预警平台提供三维应用服务满足对三维数据应用服务要求，三维数据应用率和提高工作效率。

（5） 信息标准化体系

信息标准化体系主要满足信息资源共享的需要。为业务部门信息系统集成和整合提供标准。解决业务部门信息系统的数据多源性和多重性问题，提供系统集成依据和信息采集、传输、交换、存贮、处理和共享等环节制定或采用的相关技术标准。

（6） 安全防护体系

安全防护体系是指提供系统软硬件方面整体安全性的所有技术工具和措施的总和，依据平台设计对安全防护方面的要求，实现对三维数据中心的全面安全防护。防护措施覆盖平台各个部分，包括数据安全、应用安全、系统安全、网络安全等。

1.4.3. 部署架构

电网三维数据中心采用省公司侧一级部署，三维数据资源采用分布式存储管理方式，技术架构支持后期整体迁移上云操作，电网三维数据中心提供三维数据管理功能、三维数据共享应用服务、典型业务场景三维应用服务。软件内容主要为操作系统、运行环境、管理软件、应用程序及数据库等，系统运行环境符合国网信息化安全策略。

电网三维数据中心部署运行环境设计主要遵循以下基本原则：

（1）基于自建管控系统技术框架基础上进行建设

（2）资源利旧原则、可扩展性原则，支持后期方便迁移上云

（3）最大限度的满足用户的工作需要；

（2）在保证系统功能的前提下，尽可能的降低资金投入；

（3）可靠性原则包括性能可靠性、使用可靠性和维护可靠性；

（4）考虑一定时期内技术的先进性及软硬件间的兼容性；

（5）可升级原则，由于软硬件产品更新较快，必须充分考虑系统的可升级性（或可扩充性），支持后期方便迁移上云。

1.4.4. 安全架构

电网三维数据中心安全防护体系和电网智能运检管控系统安全防护体系一致，依据《国家电网公司智能电网信息安全防护总体方案》（国家电网信息〔2011〕 1727 号）要求，遵循“分区分域、安全接入、动态感知、全面防护 ”的安全策略，按照等级保护二级系统要求进行安全防护设计，最大限度的保障的安全、可靠和稳定运行。

1.5.8. 创新点

实现了基建全过程数据资料的“一键式 ”移交。同时国网湖南省电力公司按照“ 中台+应用 ”建设模式，基于“ 中台+微服务 ”的 IT 架构，开展电网设备三维数据中心建设，新增三维数据管理、三维数据规模共享及纵向同步。统一新建工程三维数据建模与移交标准，目标是“一站式 ”入库。实现三维数据共享应用。变电站和输电线路三维成果共享（运检、基建、调度之间共享），总部和省公司纵向数据贯通（总部与省公司之间共享）。基于电网设备三维数据中心，完成为各部门各专业应用系统提供统一的三维数据共享服务。

通过使用架空输电线路自动参数化建模模型库和建模工具，实现通用模型高度复用，避免重复建设，降低建模成本；快速高效地创建架空输电线路三维模型，有效提高架空输电线路三维建模效率。
